# 🌿 Plant Disease Classification

![Banner Plant Disease Classification](data/plant.avif)

Repositório dedicado ao desenvolvimento de modelos de **Visão Computacional** e **Deep Learning** para a identificação e classificação automática de doenças em folhas de plantas a partir de imagens.

---

## Objetivo do Projeto

Doenças agrícolas são uma das principais causas de perdas na produção de alimentos. Este projeto tem como objetivo construir e avaliar modelos de aprendizado profundo (como Redes Neurais Convolucionais - CNNs) capazes de diagnosticar rapidamente se uma planta está saudável ou infectada por uma patologia específica através de fotos de suas folhas.

---

## Dataset (Conjunto de Dados)

Os dados utilizados neste projeto são baseados no dataset **PlantVillage**, disponível publicamente no Kaggle:

🔗 **Fonte original dos dados:** [PlantVillage Dataset - Kaggle](https://www.kaggle.com/datasets/emmarex/plantdisease/data)

O dataset utilizado contém **15 classes** distribuídas entre folhas de **Pimentão** (2 classes), **Batata** (3 classes) e **Tomate** (10 classes), abrangendo plantas saudáveis e diferentes patologias---
